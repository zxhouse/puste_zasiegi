repozytorium Google Fonts (`github.com/google/fonts`, katalog `ofl/`). Wszystkie są na licencji **SIL Open Font License 1.1**
(pełny tekst: `OFL-1.1.txt`; w każdym podfolderze plik `LICENSE-copyright.txt` z pakietu Debiana z autorami i licencją).
